# Go Platform Lab

Production-grade infrastructure tools built in Go.

## Motivation

This repository contains infrastructure projects inspired by real-world platform engineering problems, including concurrent health checking, Kubernetes tooling, reverse proxies, rate limiting, retry frameworks, metrics instrumentation, and distributed systems concepts.

## Projects

- Health Checker
- Retry Library
- Worker Pool
- Kubernetes Inspector
- Reverse Proxy
- Rate Limiter
- Infrastructure Orchestrator

## Tech Stack

- Go
- Kubernetes
- Prometheus
- Docker
- GitHub Actions

## Learning Goals

- Production Go
- Concurrency
- Distributed Systems
- Reliability Engineering
- Platform Engineering
